# Wolverine Anatomy Tool 1.1 Beta 1

This prerelease captures the current development work since 1.0 Beta 1: connected surface and attachment changes, updated controls and idle gestures, and the experimental unified constraint solver.

Download and extract `WolverineAnatomyTool-1.1-beta.1.zip`, close the game, and run `Install.cmd` or `Upgrade-Beta-1.1.cmd`. Saved controls are preserved. `Rollback-Beta-1.1.cmd` restores the files present before installation. Supported local game packages are required.

The snapshot passes its build, control/persistence checks, seven deterministic motion/rendering cases, and clean-install/upgrade/rollback fixtures. Live gameplay feel and performance remain unverified. Surface folds and contact artifacts can still occur; this beta does not claim to finish the physics work.

The release includes the current runtime, existing texture/audio payloads, source, validation results, and SHA-256 checksums.
