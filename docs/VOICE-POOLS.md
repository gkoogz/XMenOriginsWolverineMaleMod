# Wolverine voice pool transcript

This is a transcript/provenance record for the two voice pools installed with the Wolverine mod under `C:\Games\X-Men Origins Wolverine\Binaries\TeachingAudio`. The clip list and file-size evidence are in [wolverine-voice-pools.csv](wolverine-voice-pools.csv).

The runtime WAV files have generic `clip-NN.wav` names. Original-name records remained in the Windows Recycle Bin for deleted MP3 source files. I matched each installed WAV to its MP3 by decoded duration and 10 ms RMS audio-envelope correlation; each selected match scores 1.000. The CSV retains exact filename text, source MP3 bytes, installed WAV bytes, duration and match evidence. It contains no audio binaries.

The observed installed pools contain 13 Phase 1 clips and 11 Phase 2 clips. The older synthetic cue regression sets pool counts to 13 and 7; its expected Phase 2 count is not the count of the current installed WAV directory. The transcript preserves the original filename wording and spelling exactly; it records filename-encoded text rather than a new speech-to-text interpretation.
The source MP3 sizes in the CSV agree with the byte counts stored in each matching recoverable Recycle Bin payload.
