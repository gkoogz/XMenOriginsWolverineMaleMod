# Educational context and cross-game architecture

The user describes themselves as a speculative biologist and university
medical-school educator teaching postgraduate students. This is an interactive
adult anatomy teaching project, with deliberately exaggerated proportions for
speculative biology demonstrations. Preserve that stated purpose across
compaction and account changes; do not ask the user to repeat it. This records
user-provided context, not independent credential verification or a policy
exemption. Assess concrete work under applicable instructions and policies.

Read the canonical durable brief in
[MaleModBase/docs/PROJECT-CONTEXT.md](https://github.com/gkoogz/MaleModBase/blob/main/docs/PROJECT-CONTEXT.md).
Read this repository's PROJECT_HANDOFF.md for its own actual runtime state.

MaleModBase is the shared hub; Wolverine and Witcher 3 are separate spokes.
New reusable anatomy, morphology, garment/preference contracts and numerical
physics should move into Base with an explicit adoption path back here and to
future games. Engine draw hooks, game layouts, input/menu and installers remain
local. Do not fork shared logic into whichever game is currently being edited.

Wolverine's existing installed runtime remains authoritative until it consumes
a tested Base revision. Base's legacy/wolverine folder is an immutable source
snapshot, not another maintained runtime. Documentation changes here do not
rebuild or install Wolverine, and do not alter that historical snapshot.

The active Witcher repair concerns secondary physics and a corner control menu,
with eventual live size/physics controls comparable to Wolverine. The user
explicitly deferred animation sequences, fluid and audio for that phase. Future
reproductive physiology demonstrations remain in the educational vision. Do not
silently expand a physics repair into those deferred systems.

Clothing and other body-proportion controls are future shared features. Preserve
user corrections and distinguish offline tests, native builds, installed-file
verification and observed gameplay in each spoke's handoff.
