# v0.9

This release packages the current R36-based build with attachment/surface refinements, oblique resting shape, a shallower central dip, bounded shaft motion, animated-chest necklace contact, and state-specific skin texture variants.

Download **WolverineAnatomyTool-v0.9.zip**, extract all files, close the game, and run **Install.cmd** or **Upgrade-0.9.cmd**. Saved settings are preserved. **Rollback-0.9.cmd** restores the files replaced by this release.

Clean-install and upgrade fixtures passed reconstruction, checksums, settings preservation, texture backup, and exact rollback. Development runtime and render-state tests passed.

**Known limitations:** the newly reported underside indentation remains unresolved. Extreme-pose collision artifacts remain possible. Necklace contact is corrected at rendering time. Texture detail is diffuse-only, and live visual validation is incomplete.
