# Wolverine Anatomy Tool 1.0 Beta 1

This beta packages the currently installed build. Erection, Throb, and Idle Chatter appear above the sliders, with F6 show/hide labeled in the header and legend. Four throb settings animate size and angle. Idle Chatter switches immediately between standard cues and a pool containing the three original clips and 19 supplied clips, using the existing spoken idle animations.

Download `WolverineAnatomyTool-1.0-beta.1.zip`, extract every file, close Wolverine, and run `Install.cmd` or `Upgrade-Beta-1.0.cmd`. `Rollback-Beta-1.0.cmd` restores the files present before installation. Saved settings are preserved.

The user heard new idle audio in Weapon X. Clean-install and upgrade fixtures verified package reconstruction, every payload and audio checksum, settings preservation, and exact rollback. The runtime and rendering harness passed.

**Known limitations:** the underside ridge still ends prematurely and remains unresolved. Extreme poses can show contact artifacts. The longer custom clips use existing talking animation without matching lip sync. Later chapters and every individual clip have not been checked in-game.
