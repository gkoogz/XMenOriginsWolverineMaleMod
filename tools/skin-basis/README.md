Requires local Capture168_20260916_055428 under the game Binaries directory, VC x86 BuildTools and DirectX SDK June 2010. No keyboard injection or game launching. The D3D window is hidden.

Run build.cmd, then replay.exe original and replay.exe world_skin for the isolated experiment and corrected bytecode files. Run build_hook.cmd, then hook_replay.exe hook_verified for the actual runtime hook regression checks and image. Exit 0 is success. Cubemaps were absent from the capture: neutral placeholder cubemaps and disabled environment strength are identical across replay modes, not runtime changes.
