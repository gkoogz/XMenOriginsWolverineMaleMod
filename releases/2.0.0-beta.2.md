## Installation

Extract the entire Install.7z with7-Zip. Close the game and run Install.cmd or
Upgrade-Beta-2.0.cmd. For a custom install use
`Install.ps1 -GamePath 'D:/Games/Wolverine'`. Supported stock or exact approved
Natural/WGame/WStart packages are accepted. Unsupported modifications are
rejected before writes. No previous mod release is required.

Rollback-Beta-2.0.cmd / Uninstall.cmd restore the preceding files from
`WGame/ModBackups/WolverineAnatomyTool-v2.0.0-beta.2`. Existing shape/fluid/camera
preferences and private TeachingAudio remain intact. The complete payload
includes all required deltas/maps/public default audio/defaults and validators.
SHA256SUMS accompanies both upload archives and the expanded installer.

## Evidence and limits

The exact approved source and Base headers rebuilt cleanly. The distributed DLL
retains the observed installed bytes rather than substituting a different rebuild. Several PE sections differ;
the clean build is compile proof, not reproducible binary identity. Previous production pose/worker/shader/offscreen render and native grey
room animation, F6/Overall and garment observations are recorded in the handoff.
Fresh Beta2 clean install, supported upgrade, exact rollback, preferences,
existing-texture backup, custom fluid/camera and unsupported-input rejection
fixtures passed. These installer fixtures do not prove every live pose/material
or garment contact state. No new whole-game performance guarantee is made.

The grey development room is tracked in the repository only. Uploaded Install
and optional Source assets exclude it, its dependencies, private profiles and
captures. Git tag source snapshots exclude the room through .gitattributes export-ignore;
clone Git to obtain development tools.
